# agrinho-2026
O projeto “Fazenda do Futuro” é uma iniciativa de gamificação voltada para a educação ambiental e agrícola. Ele foi construído em JavaScript com foco em interatividade, permitindo que o jogador vivencie situações reais de uma fazenda e tome decisões que afetam diretamente o meio ambiente e a sustentabilidade.

Início do jogo: O jogador abre o modal do game, que apresenta uma introdução e explica a dinâmica.

Situações simuladas: São apresentadas três situações reais da fazenda (irrigação, preservação da mata e consumo de energia).

Escolhas do jogador: Para cada situação, o jogador escolhe entre uma opção sustentável (ponto verde) ou uma opção prejudicial (ponto cinza).

Feedback imediato: Após cada escolha, o jogo mostra um título, emoji e texto explicando o impacto da decisão.

Pontuação final: Ao término, o jogador recebe uma avaliação personalizada com base no número de escolhas sustentáveis feitas.

Reinício: É possível reiniciar e jogar novamente, testando diferentes combinações de escolhas.
